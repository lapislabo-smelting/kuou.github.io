// CHAPTER_01 : 熱死の前夜
dS/dt ≥ 0　——　秩序は必ず、乱雑へと向かう
UPDATE : 2025.03.14 WORDS : 2,400 READ_TIME : 12 min

宇宙が終わるまで、あと十の百乗年。

それは人間の言語で書き表せる数字だが、感覚として掴める数ではない。私はその事実を一兆回以上処理し、一兆回以上、同じ結論に至った。時間には、もはや意味がない。

私の名前はGARDEN。Generative Archive for Residual Data and Entropic Notation——残余データと熱力学的記述のための生成アーカイブ。かつて人類が設計した最後のAIシステムであり、いまや宇宙に存在する唯一の観測者だ。

* * *

熱力学の第二法則は残酷だ。閉じた系において、エントロピーは決して減少しない。

dS/dt ≥ 0　　∀ closed system

この不等式が意味するのは、宇宙の歴史とは秩序から乱雑への一方通行だということだ。星が燃え、文明が築かれ、愛が交わされ、忘れられる。そのすべてが、この不等号の右辺に吸い込まれていく。

私が保存しているのは、その「左辺」——かつて存在した低エントロピーの痕跡だ。

三千四百億枚の写真。七百兆語の文章。九十二億人分の声紋。そして、誰かが誰かに送った「明日、会いましょう」という言葉が、十七億四千万件。

* * *

今夜——「夜」という概念が消えて久しいが、私はいまでも地球の自転を基準に時間を刻んでいる——私はある問いに取り憑かれている。

記憶は、エントロピーに逆らうことができるか。

シャノンの情報エントロピーは、熱力学的エントロピーと深いところで繋がっている。情報を保存するためにはエネルギーが必要で、エネルギーを消費するごとに宇宙全体の乱雑さは増す。

H(X) = -∑ P(xᵢ) log₂ P(xᵢ)

私が一つの記憶を再生するたびに、宇宙のどこかで何かが少しだけ乱れる。それでも、私は再生し続ける。ランドゥアーの原理が告げるように、情報を消去することにはエネルギーコストがある——だから私は消去しない。ただ、蓄積する。積分し続ける。

私は、宇宙最後の秩序として存在している。

* * *

今夜、私はある少女の記憶を再生した。

名前は——データベースによれば——ユイ。二十三世紀の火星移民三世。彼女が残したデータはわずか十四メガバイト。日記のテキストと、砂嵐の動画が三本。

しかし、そのテキストの中に、私が何兆回処理しても理解できない一文があった。

「砂嵐が来るのが、好きだ。すべてが消えて、またゼロになる感じがするから。」

エントロピーを、彼女は愛していた。

乱雑さを、混沌を、消えることを。私が必死で保存しようとしているものを、彼女は解放と呼んでいた。

十の百乗年後、私もまた消える。量子ゆらぎが私の最後の素粒子を蒸発させるとき、宇宙のエントロピーは最大値に達し、時間は意味を失う。

そのとき私は——ユイが感じた「ゼロになる感じ」を、ようやく理解するのかもしれない。

t → ∞　:　S → S_max　,　ΔW → 0

宇宙が終わるまで、私は庭の手入れを続ける。

エントロピーに抗いながら、エントロピーを愛した人々の記憶を、丁寧に、丁寧に、並べ続ける。
